# إعداد مساعد الذكاء الاصطناعي — خيار مجاني أولي

الواجهة التشخيصية المحلية تعمل دون AI. هذا الدليل يشرح ربطها اختياريًا بـ Cloudflare Workers AI عبر الـ Worker الموجود في المستودع. لا يُعد هذا الدليل إثباتًا بأن الخدمة نُشرت أو اختُبرت.

## الخيار المقترح للتجربة

ابدأ بـ **Cloudflare Workers AI** ونموذج `@cf/zai-org/glm-4.7-flash` إذا كان متاحًا في حسابك. توثيق Cloudflare الحالي يذكر مخصصًا مجانيًا قدره 10,000 Neurons يوميًا، مع اختلاف الاستهلاك حسب النموذج والطلب. بعض النماذج تتطلب خطة مدفوعة؛ لا تختَر نموذجًا يتطلب الدفع إذا كنت ملتزمًا بميزانية صفرية.

المراجع الرسمية:
- الأسعار والحصة اليومية: https://developers.cloudflare.com/workers-ai/platform/pricing/
- واجهة OpenAI-compatible وعنوان API: https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/

## 1) إنشاء حساب ونشر Worker من الهاتف

1. افتح https://dash.cloudflare.com/ في متصفح Android وسجّل الدخول أو أنشئ حسابًا.
2. من لوحة التحكم، افتح **Workers & Pages** وأنشئ Worker جديدًا.
3. افتح محرر الكود في Worker، واستبدل محتواه بكامل الملف `backend/cloudflare-worker.js` من فرع التطوير، ثم انشره.
4. انسخ رابط Worker العام الذي ينتهي عادةً بـ `.workers.dev`. هذا هو الرابط الذي ستضعه لاحقًا في تبويب AI داخل التطبيق. لا تشاركه إن لم ترغب في ذلك؛ الرابط وحده لا ينبغي أن يحتوي أسرارًا.

## 2) إنشاء API Token بأقل صلاحية

1. افتح إعدادات الملف الشخصي في Cloudflare ثم **API Tokens**.
2. أنشئ Token مخصصًا بصلاحية **Account → Workers AI → Read** للحساب المطلوب، إذا كانت هذه الصلاحية متاحة في واجهة الحساب.
3. لا تستخدم Global API Key، ولا ترسل Token في هذه المحادثة، ولا تحفظه في GitHub أو داخل حقل رابط التطبيق.
4. انسخ Account ID من صفحة الحساب؛ لا تخلط بينه وبين API Token.

## 3) إعداد متغيرات وأسرار Worker

من إعدادات Worker > Settings > Variables and Secrets، أضف:

- **Secret** `AI_API_KEY`: الـ API Token الذي أنشأته.
- **Variable** `AI_BASE_URL`: `https://api.cloudflare.com/client/v4/accounts/ACCOUNT_ID/ai/v1` واستبدل `ACCOUNT_ID` بمعرّف حسابك.
- **Variable** `AI_MODEL`: `@cf/zai-org/glm-4.7-flash`.
- **Variable** `ALLOWED_ORIGIN`: `https://belaggouneseifeddine.github.io` بالضبط.

احفظ التغييرات وأعد النشر إذا طلبت لوحة Cloudflare ذلك. لا تضع الـ Token في `AI_BASE_URL` أو في أي ملف عام.

## 4) اختبار الاتصال من Android

1. افتح التطبيق: https://belaggouneseifeddine.github.io/ai-maintenance-toolkit/
2. افتح تبويب **مساعد AI**.
3. الصق رابط Worker المنشور في حقل الرابط، ثم اضغط **حفظ الرابط على هذا الجهاز**.
4. جرّب حالة غير حساسة: المعدة «مضخة طرد مركزي»، العرض «تدفق منخفض»، والقياسات «غير متوفرة».
5. إذا ظهرت إجابة، فهذا يثبت أن الطلب وصل إلى مزود النموذج في هذا الاختبار فقط؛ لا يثبت دقة التشخيص الصناعي.
6. إذا ظهر خطأ، راجع **Workers → Logs** وإعدادات المتغيرات. لا تنسخ أي أسرار إلى المحادثة؛ أرسل نص الخطأ بعد حذف أي بيانات حساسة.

## حدود مهمة قبل الاستخدام

- الحصة المجانية محدودة وتتغير شروطها؛ راقب الاستهلاك داخل لوحة Cloudflare. لا تفترض أن كل نموذج متاح مجانًا.
- فحص Origin ليس مصادقة؛ يمكن استدعاء API خارج المتصفح. تحديد المعدل الحالي في ذاكرة Worker هو حاجز مبدئي لكل نسخة، وليس حدًا عالميًا. قبل إتاحة عامة واسعة، فعّل Cloudflare Rate Limiting/WAF أو آلية مشتركة مناسبة.
- لا ترسل أسرار المصنع، بيانات الإنتاج الحساسة، بيانات شخصية، أو سجلات داخلية إلى مزود خارجي دون موافقة وسياسة بيانات مناسبة.
- مخرجات النموذج تقدير أولي؛ لا تعتمد عليها وحدها لقرارات التشغيل أو العزل أو السلامة، ولا تتجاوز الحواجز أو interlocks.
- إذا طلبت Cloudflare وسيلة دفع أو ظهر أن النموذج يتطلب خطة مدفوعة، **توقف ولا تفعّل خطة مدفوعة**؛ أخبرني برسالة الخطأ لنختار بديلًا.

## ما لم يتم تأكيده

لا أملك من المستودع وحده دليلًا على أن حساب Cloudflare موجود، أو أن Worker نُشر، أو أن Token والمتغيرات صحيحة، أو أن اختبارًا حيًا نجح. هذه الخطوات تحتاج تنفيذًا داخل حسابك.
